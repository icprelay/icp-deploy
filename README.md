# ICP Relay deployment wrapper

This project pulls the latest release from `icprelay/icp-core` repository.

## Requirements

- Azure DevOps account
- Azure Service Connection (ARM) named `icp-azure-connection` 
- Git Service Connection (AzurePipelines) named `icp-git-connection` 

## Installation Guide

Make a copy of the `INSTALL.md.template` and rename it to `INSTALL.md` and follow the instructions in the document.
